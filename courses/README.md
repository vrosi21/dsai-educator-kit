# Your course goes here

Download your course's files from the site (Educators, **Download the course files**) and
unpack the zip into this folder:

```
courses/
  rl/
    course.yaml
    content/        what the site shows: your assistant writes here
    source/         you add this: slides, labs, homework, past papers
```

Git ignores everything in this folder except this note. Nothing here is committed or
pushed, and updating the kit with `git pull` never changes it.
